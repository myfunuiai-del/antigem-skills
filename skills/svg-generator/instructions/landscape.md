# Landscape tracing hints

- Anchor composition on a horizon line: a single `stroke-sil` path separating sky from ground/water, placed per the source image's actual horizon height (not always centered).
- Author every `class="fill"`/`class="stroke-sil"`/`class="stroke-int"` shape as a curved `<path>` (with at least one `Q`/`C` command), `<circle>`, or `<ellipse>` — never a `<polygon>` or `<rect>`, per SKILL.md's **Line rules**. Even geometric scene elements with straight real-world edges (buildings, fences, mechanical structures) must be traced as gently curved `<path>`s, not polygons.
- Use large, simple `class="fill"` regions for sky, ground, and any dominant mass (mountains, water, foliage) — keep each region's color drawn from the fixed palette, no gradients.
- Foreground elements (trees, rocks, structures) get their own small `class="stroke-int"` outlines regardless of size — canvas.py scales the wobble/width floor down proportionately for small shapes (see SKILL.md), so class them normally rather than leaving them unclassed. Don't let foreground outlines compete with the horizon line for visual weight.
- Target 8-12 `class="fill"` regions for a typical landscape (sky, ground/water, 1-2 dominant masses like mountains or tree lines, plus 3-6 foreground/midground elements) — this is well within SKILL.md's fill-region ceiling. Merge only genuinely similar background elements (e.g. a row of distant hills) into one fill; don't collapse the whole scene into 2-3 regions just to stay "simple" — under-filling reads as sparse against approved targets the same way an object drawn as one blob does.
- **Named failure mode — do not do this:** tracing only sky + ground + a single foreground mass and calling the scene complete. A landscape with no midground/foreground detail reads as empty even if the horizon and palette are correct — always add the distinguishing foreground elements (trees, rocks, structures, water texture) the source actually shows.
- Background fill should reflect the scene's actual sky/ground colors drawn from the source — there is no default background to fall back on.
