# Animation Assets Library (`animation-assets/<style>/modules/`)

এই ডিরেক্টরিতে প্রতিটি অ্যানিমেশন স্টাইলের জন্য টেস্টেড ও ভেরিফাইড পুনঃব্যবহারযোগ্য মডিউল রাখা থাকে।
নতুন প্রজেক্ট বা সিনে স্ক্র্যাচ থেকে কোড না লিখে এই মডিউলগুলো ইম্পোর্ট করে কাজ করতে হবে যাতে **টোকেন খরচ ৮০% কমে যায়** এবং প্রফেশনাল মান বজায় থাকে।

## স্টাইল অনুযায়ী ফোল্ডার বিন্যাস:
- `animation-assets/3d-movie/modules/`:
  - `lighting.js` -> ACES টোনম্যাপিং, IBL PMREMGenerator, নরম সানলাইট ও রিম লাইট।
  - `water.js` -> ৫-অক্টেভ নন-গ্রিড GLSL নদী/সমুদ্র ওয়াটার শেডার।
  - `foliage.js` -> ৪-স্তরের আলপাইন পাইন গাছ এবং মিয়াজাকি ব্রডলিফ ট্রি ক্লাস্টার।
  - `camera-drone.js` -> ৩-বিটের সিনেমাটিক ড্রোন ক্যামেরা কার্ভ এবং স্মুথ প্যাথ ট্র্যাকিং।
  - `vehicles.js` -> (ট্রেন, বাস, কারের চাকা/বডি প্যারামেট্রিক ফ্রেমওয়ার্ক)।
  - `city.js` -> (শহরের বিল্ডিং, নিয়ন লাইট, রাস্তা ও ফুটপাত)।
- `animation-assets/anime/modules/` -> অ্যানিমে ব্যাকগ্রাউন্ড, ক্লাউড ও সেল-শেডিং।
- `animation-assets/stickman/modules/` -> স্টিকম্যান ফিজিক্স, হ্যান্ড-ড্রন লাইন।
- `animation-assets/claymation/modules/` -> ক্লে ম্যাটেরিয়াল, ফিঙ্গারপ্রিন্ট বাম্প ও স্টপ-মোশন স্টেপিং।
- `animation-assets/kurzgesagt/modules/` -> ভেক্টর গ্রাফিক্স, স্টারফিল্ড, ফ্ল্যাট-কালার অ্যাসেট।
